# 字体抓取工作台

个人使用的缺失字体处理工具：上传 Adobe Illustrator 缺失字体截图做 OCR，或直接粘贴多个字体名，实时搜索候选来源，并把可直链下载的字体打成 zip。

## 启动

最简单的方式：双击 `start-font-hunter.cmd`，它会启动服务并打开浏览器。

也可以在当前目录运行：

```bash
npm start
```

打开：

```text
http://localhost:4173
```

## 当前能力

- 上传 AI 缺失字体截图，通过浏览器端 OCR 提取字体名。
- 支持每行一个字体名的批量搜索。
- 自动过滤 Illustrator 弹窗里的无关文字。
- 通过搜索引擎聚合候选来源。
- 探测候选页面里的 `.ttf`、`.otf`、`.woff`、`.woff2`、`.zip` 下载链接。
- 对可直链下载的结果打包为 zip，并附带 `来源说明.txt`。

## 注意

- OCR 使用在线脚本，第一次加载需要网络。
- 搜索和下载依赖目标网站可访问性，遇到验证码、登录、网盘或付费字体时，只展示来源链接。
- 这个工具不会检查本地字体库，也不会保存历史缓存。
